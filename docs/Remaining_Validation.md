# Remaining frozen validation — requires authenticated model access

This is a blocked extension, not completed evidence. It is not needed to reproduce any reported table.

## Required inputs

1. Official minutes released after the legacy 2024 sample and by the fixed September 19, 2026 cutoff. Eligible meeting dates identified from the official calendar: 2025-01-29, 2025-03-19, 2025-05-07, 2025-06-18, 2025-07-30, 2025-09-17, 2025-10-29, 2025-12-10, 2026-01-28, 2026-03-18, 2026-04-29, 2026-06-17, 2026-07-29. The September 2026 minutes are not included merely because the meeting occurred.
2. Authenticated output from the existing embedding and Flash configurations, with original passage extraction, model IDs/resolved revisions, exact text hashes, and immutable request/response records. No API secrets should be included in a returned archive or pasted into a manuscript.
3. Genuine daily market observations spanning all target windows, with no stale forward fills beyond last genuine source dates. Download and retain the official French daily factors as an additional independently sourced criterion; record the data vintage and distinguish the broader market portfolio from S&P 500 prices.

## Before examining outcome performance

Freeze code/configuration hashes and dates. Keep the original 2000–2024 development sample and fit preprocessing/penalties there using chronological inner folds. Do not tune on the new evaluation outcomes. Decide in advance whether coefficients remain fixed across all new meetings (recommended for this small diagnostic); do not select between fixed and sequential updates based on their results.

Preserve the existing Gemini-plus-length model and Flash five-category specification. Apply the same audited automatic counts, their fixed quadratic readout, and TF-IDF. Original authors' human counts stop in 2016 and cannot be invented for the new period. This holdout tests current automated procedures; the original-human comparison remains the source-period exercise.

No provider substitution or model-version change may be hidden. If the exact legacy version cannot be invoked, mark the extension as version-dependent and do not combine it with the old cache as an identical-model intervention. A researcher-uninspected holdout is not automatically pretraining-clean.

## Return

Return immutable source files/hashes, extracted passages, all raw vectors/labels, one prediction row per model and meeting, target construction ledger, conditional paired losses, MSE/RMSE/MAE, historical-mean-relative R², missingness/failure log, and complete code. Keep the full fixed sample regardless of whether gains are favorable. Thirteen observations can have wide uncertainty; they are not a guaranteed high-powered confirmation.

The provided acquisition script can retry official downloads, but no actual new model outputs are included in this package. A favorable comparison is not the condition for releasing the extension.
